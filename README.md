# Musubi Dojo Jurbise — nouveau site

Proposition de nouveau site web (one-page, responsive) pour l'École d'Aïkido **Musubi Dojo** de Jurbise,
destiné à remplacer l'ancien site `jurbise.aikido.be`.

## Aperçu

Site statique, un seul fichier `index.html` (CSS et JavaScript intégrés) + un dossier `images/`.
Aucune dépendance à installer, aucun build.

### Sections
- Accueil (hero)
- L'Aïkido (présentation de l'art)
- Le Dojo : horaires, tarifs, inscription + carte
- Professeurs
- Notre histoire (frise 1987 → aujourd'hui)
- Techniques
- Actualités & In Memoriam
- Contact

### Caractéristiques
- Design responsive (mobile, tablette, desktop) avec menu adapté
- Charte inspirée du blason du dojo (encre, vermillon, papier washi, motifs japonais)
- Animations discrètes à l'apparition, retour en haut de page
- Balises SEO / Open Graph, repli si JavaScript est désactivé

## Voir le site

- **En ligne :** via GitHub Pages (voir l'onglet *Settings → Pages* du dépôt).
- **En local :** ouvrez simplement `index.html` dans un navigateur.

## À valider par le club
- Grades des professeurs (quelques incohérences entre les pages de l'ancien site).
- Actualités et date de reprise à mettre à jour chaque saison.
- Idéalement, fournir des photos du dojo en haute résolution.
